# 题目包 / Question Package

## 中文

每个子目录包含完整题面、答题骨架、公开测试和判据。按该题的 README 写代码并运行测试。涉及文件格式的题目另附二进制样例，保留原始字节即可。

如果也下载了答案包，把两个 ZIP 解压到同一目录。根目录的 compare.py 可以在临时副本里对照参考实现。

## English

Each directory contains a complete specification, starter code, public tests, and acceptance criteria. Follow the problem's README to implement and test your solution. File-format problems include binary samples whose bytes must be preserved.

To cross-check reference implementations, extract the question and answer ZIP files into the same directory and run compare.py from that directory.
