# 有限整数域上线性同余组的计数与排名 / Counting and Ranking Linear Congruence Solutions over Finite Integer Domains

[中文](#中文) · [English](#english)

## 中文

### 解析

1. 将各约束行的模数组成乘积群的坐标，并按素幂分解。对某个变量后缀预计算其列向量生成的像，通过素幂上的消元判断剩余右端是否在像内。
2. 可行时同一像中的所有原像纤维大小相同。用域大小乘积与像的阶计算纤维大小。固定前缀时将其贡献从右端扣除，并把下一变量的可行值写成等差剩余类。
3. 排名将字典序更早的前缀块大小相加，反查依照这些块跳过整段可行后缀。不同模数、相关方程和域长 1 都由各素幂的成员测试和精确整数计数统一处理。

## English

### Solution

1. Treat row moduli as coordinates of a product group and split them into prime-power components. Precompute the image generated by the columns of each variable suffix. Elimination over prime powers decides whether the residual right-hand side belongs to that image.
2. When feasible, all fibers over the image have the same size. Compute that size from the domain product and image order. Subtract the fixed prefix from the right-hand side and express feasible values of the next variable as a residue class.
3. Ranking adds the sizes of lexicographically earlier prefix blocks. Unranking skips entire blocks of feasible suffixes. Different row moduli, dependent equations, and size-one domains are handled by prime-power membership tests and exact integer counts.
