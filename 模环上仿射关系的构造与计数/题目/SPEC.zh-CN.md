# 模环上仿射关系的构造与计数 / Construction and Counting of Affine Relations over Modular Rings

## 1. 你在维护什么

固定一个模数m。一个宽度d的“回路”表示一个集合：

`S ⊆ {0,1,...,m-1}^d`。

坐标是可见端口。构造、连接和查询都只谈这个**集合**，不保存某个结果有多少种内部实现。
如果许多不同的中间状态映射到同一个可见元组，它们在结果集合里只算**一个**。

所有生成方式都由模m线性同余、仿射映射、交集、连接和投影构成。
集合可能为空。m可以是合数、素数幂或大合数；不能默认非零数都有逆元。

回路保存在编号0..255的槽位。槽位保存值：后续覆盖一个槽位，不改变其他槽位此前复制或算出的集合。
一次命令里的所有源槽位都读取**命令开始前**的值，再写入dst。因此dst可以等于src、left或right。

## 2. 协议与限制

输入、输出均为UTF-8 NDJSON：每行一个JSON对象。所有输入保证合法，无须处理非法操作。
每读取一行，就必须输出并flush一行响应。输入可以等待上一行响应后再决定下一条命令，不能等EOF。

- 第一条且仅第一条是init；所有源槽位保证已经赋值。
- 槽位编号：0..255。各个保存结果的宽度：0..16。
- 模数：`2 <= m <= 2^127-1`，进程中固定。
- 所有输入矩阵系数、偏置和同余右端项都是 `[-2^127, 2^127-1]` 内的JSON整数。
- 每个a最多32行；每行长度按相应命令指定。零行矩阵用 `[]`；有行但零列时用 `[[], ...]`。
- join的ties最多16项，允许重复，也允许同一端口与多个另一侧端口相连。
- keep长度0..16，索引有效，**允许重复**；按给定顺序输出坐标。
- 每个进程最多6000条命令，包括init和查询。
- 每个完整场景30秒，峰值工作集512 MiB；每条在线交互响应最多等待5秒。
- 进程计时包含解释器启动、JSON 输入输出与计算。

stdout只输出协议响应，必须用LF行尾且最后一行也有LF。stderr为空，EOF正常退出且返回码0。
响应对象的字段顺序和空格不限，字段集合、类型和值必须准确。JSON整数不接受浮点数或字符串代替，布尔也不能代替整数。

测试环境为 Windows 与 CPython 3.14.2。实现须集中在 `circuit.py`，只使用 Python 标准库。除正常导入标准库和读取本程序外，不得读取其他文件、创建持久化文件、联网、启动子进程、使用 `ctypes` 或加载系统 DLL。
可以缓存通用计算结果。程序须正确处理所有满足约束的输入，算法和内部表示不限。

## 3. 初始化

```json
{"op":"init","mod":12}
```

设置模数，所有槽位起初未赋值。响应 `{"ok":true}`。

## 4. 构造与更新槽位

以下命令都响应 `{"ok":true}`，包括构造出空集合的情况。
没有输入输出端口的隐式区分，所有坐标同等；也没有隐式的非零、可逆或单解保证。

### make：同余方程组

```text
{"op":"make","dst":h,"dim":d,"a":[...],"b":[...]}
```

a有r行、d列，b长度r。在dst保存所有满足 `a*x ≡ b (mod m)` 的d维元组。
没有方程时就是全空间，不是空集合；矛盾方程产生空集合。

### map：仿射像

```text
{"op":"map","src":s,"dst":h,"a":[...],"b":[...]}
```

若src宽度为d，a有e行、d列，b长度e，则结果宽度为e，保存：

`{ (a*x+b) mod m : x ∈ src }`。

**重复结果必须合并。** a可以奇异，可以有零行或重复行。

### pin：施加条件

```text
{"op":"pin","src":s,"dst":h,"a":[...],"b":[...]}
```

若src宽度为d，a有r行、d列，b长度r，保存：

`{ x ∈ src : a*x ≡ b (mod m) }`。

结果仍是d维。它与map不同：pin筛选原元组，map计算新元组。

### meet：交集

```json
{"op":"meet","left":1,"right":2,"dst":3}
```

左右宽度保证相同，结果为两集合的交集。

### join：独立复制、连接、隐藏

```text
{"op":"join","left":l,"right":r,"dst":h,
 "ties":[[i,j],...],"keep":[k0,k1,...]}
```

设left宽度p、right宽度q。先独立取 `x ∈ left`、`y ∈ right`，要求每项 `[i,j]` 满足 `x[i]=y[j]`（模m的标准代表相等）。
然后把 `z=x+y` 作为长度p+q的**元组拼接**，保留 `(z[k0],z[k1],...)`，合并所有重复结果后写入dst。
这里x+y不表示逐元素加法。keep的0..p-1来自左侧，p..p+q-1来自右侧。
未保留坐标被隐藏：只要求存在，不计算它们有多少种取值。

特别地，即使left和right指向**同一槽位**，取出的x和y仍是两份独立选择；只有ties明确规定的等式才连接它们。
使用同一槽位不是自动共享其所有内部变量。

### copy：保存槽位值

```json
{"op":"copy","src":1,"dst":2}
```

dst取得src当前的集合。后续覆盖src不影响dst。

## 5. 查询

所有查询都不改变任何槽位的数学值。

### ask：计数与最小结果

```json
{"op":"ask","src":1}
```

响应恰好为：

```text
{"dim":d,"count":C,"first":F}
```

- C是集合中**不同元组的精确数量，不取模**。
- 非空时F是字典序最小元组，表示为长度d的JSON整数数组；各项在0..m-1。
- 字典序先比较第0项，再比较第1项，依次比较；不是按整数编码、坐标和、任意解或内部参数比较。
- 空集合C=0、F=null，仍需给出其宽度d。

### probe：临时条件与可见坐标

```text
{"op":"probe","src":s,"a":[...],"b":[...],"keep":[...]}
```

先按pin的含义临时筛选src，再按keep投影和去重，返回与ask同格式的结果，dim等于keep长度。
keep索引指向src的坐标，允许乱序和重复。它不创建或覆盖任何槽位。

### has：成员判断

```json
{"op":"has","src":1,"point":[2,1]}
```

point长度等于src宽度，输入各项保证在0..m-1。响应 `{"contains":true}` 或 `{"contains":false}`。

## 6. 容易混淆的语义例子

### 中间实现不是可见结果数

模12下，`6*x=6` 有6个解：1,3,5,7,9,11。
再映射为 `y=6*x`，结果集合只有 `{(6)}`，不是6个结果。

### 最小解不能机械拼接分模数的最小解

模6下，`2*x+3*y=1` 的解有6个，字典序最小解为 **[2,1]**。
不接受某个其他可行解，例如[2,3]。

### 零维不是空

零维全集是只含空元组的集合 `{()}`，响应 `{"dim":0,"count":1,"first":[]}`。
非空集合投影到空keep也得到此集合；空集合投影后仍为空，count=0、first=null。

### 反馈与连接不是路径计数

可以反复把已有回路与自身join，投影掉连接端口，再把结果写回原槽位。
在数学上，每一步只保存当前可见关系；旧的隐藏端口不会永久累积，内部选择的数量也不计入count。
命令描述的展开网络可能极大，资源限制照常适用。
