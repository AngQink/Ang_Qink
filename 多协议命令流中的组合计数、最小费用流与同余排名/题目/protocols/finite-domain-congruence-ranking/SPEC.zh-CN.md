# 有限整数域上线性同余组的计数与排名 / Counting and Ranking Linear Congruence Solutions over Finite Integer Domains

本页定义子协议。组合后的入口、命令前缀、资源配额及自测方式见[总题面](../../README.md)。

维护多个模数的线性同余约束，精确统计解的数量，并按字典序反查和排名。

## 1. 数学对象

固定整数 M。维护 n 个变量，每个变量有自己的定义域：

```text
0 <= x[i] < domains[i]
```

每个 domains[i] 都整除 M。维护至多 32 条线性同余行。每条行有唯一数字 id、固定模数 m、系数 a、右端 rhs 和启用状态。m 整除 M，可以为 1。启用行要求：

```text
sum(a[i] * x[i]) == rhs (mod m)
```

系数和右端都可以为负。对所有行、包括禁用行和更新后的行，输入保证 **m 整除 a[i] × domains[i]**。因此把变量值加上它自己的周期会保持每个约束。域不一定是素数幂，行模数可以彼此不同。

## 2. 运行与限制

基准环境为 Windows / CPython 3.14.2。将解法写在 `prism.py` 中，仅使用 Python 标准库。程序从标准输入读取命令，向标准输出写入回复。除导入标准库外，程序不读写文件、不联网、不启动子进程，也不调用外部本机代码。允许使用通用缓存。

- 1 ≤ n ≤ 32，0 ≤ 行数 ≤ 32。
- 2 ≤ M ≤ 2^63−1。M 由完整质因数分解 mod_factors 提供，每项 [p,e]，p 是质数、严格递增，e 为正整数。
- 1 ≤ domains[i] ≤ M，1 ≤ m ≤ M，id 为 0..2^32−1 整数。
- a[i]、rhs 均为 −2^63..2^63−1 的整数。计数及中间计算使用精确整数，可能远超 64 位。
- 每进程最多 5000 条命令，其中 query 最多 64 条。每个 query 最多 12 个 at、12 个 probes。
- 新进程运行每个场景。每进程 60 秒、峰值工作集 512 MiB。在线场景每条回复限 5 秒。
- UTF-8 NDJSON，每行一个合法 JSON 对象。每读一条立即回复并 flush，不能等 EOF。stdout 只含回复，LF 行尾，stderr 为空，EOF 退出 0。可忽略空白输入行。
- 对象字段顺序、空格不限。字段集合、类型、值和数组顺序须匹配。整数不能用布尔、浮点或字符串代替。拒绝重复 JSON 字段。

## 3. 初始化、更新和快照

第一条且仅第一条为：

```json
{"op":"init","mod_factors":[[2,2],[3,1]],"domains":[6,4],"rows":[{"id":7,"mod":6,"a":[1,3],"rhs":2,"enabled":true}]}
```

n 等于 domains 的长度。所有 a 都有 n 项。init 固定 M、各变量的域、行 id 与行模数，并清空快照。

```json
{"op":"row","id":7,"a":[-5,3],"rhs":8}
{"op":"rhs","id":7,"rhs":-4}
{"op":"enable","id":7,"value":false}
{"op":"save","slot":31}
{"op":"load","slot":31}
```

- row 原子替换该行所有系数与 rhs，保留启用状态。
- rhs 只替换该行右端。enable 只替换启用状态。禁用行可以更新。
- save 保存所有行的系数、rhs、启用状态，覆盖已有槽。load 恢复指定保存值。槽号 0..31，load 保证槽已保存。后续更新、其他槽或再次 load 均不改变已存快照。
- init、row、rhs、enable、save、load 均返回恰好 {"ok":true}。

## 4. 查询

```json
{"op":"query","prefix":[2],"at":[0,1,2,0],"probes":[[1,3],[2,1],[5,0],[2,2]]}
```

先取所有满足当前启用行且开头恰好是 prefix 的**完整向量**。prefix 长度从 0 到 n，每个值都在该位置的域内。空前缀表示不限制。将所得向量按**变量顺序、整数大小**作字典序升序排列。

- count 是此解集精确大小。
- at 与请求 at 同序。每项是从 0 开始的索引，对应一个完整向量。越界为 null。请求索引为 0..2^2048−1 的整数，可重复或乱序。
- probes 与请求 probes 同序。每个输入向量长 n，所有值在各自域内，**允许不满足 prefix 或方程**。before 是所选解集中严格小于该向量的元素数。member 表示该向量是否在所选解集中。相等的元素不计入 before。
- at 和 probes 可为空。不可行时 count 为 0，所有 at 项为 null，所有 probes 项为 {"before":0,"member":false}。仍须返回全部字段。
- query 不修改任何行或快照。

用上面的初始参数，空前缀解集依次是 [2,0]、[2,2]、[5,1]、[5,3]。上面的查询应回复：

```json
{"count":2,"at":[[2,0],[2,2],null,[2,0]],"probes":[{"before":0,"member":false},{"before":1,"member":false},{"before":2,"member":false},{"before":1,"member":true}]}
```

即使模数互有公因子、约束行线性相关或某些变量域为 1，定义都保持一致。空约束且空前缀时 count 为所有域大小的乘积。
